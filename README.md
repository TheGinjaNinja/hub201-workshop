## Technical Track Setup

1. Install [Node.js](https://nodejs.org/) 18+ if you don't have it
2. Install Claude Code:
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```
3. Clone this repo:
   ```bash
   git clone [repo-url]
   cd hub201-workshop
   ```
4. Run:
   ```bash
   claude
   ```
5. The AI coach will introduce itself and guide you through the exercises

## Low-Tech Track Setup

1. Download files from the `low-tech/` folder
2. Open in PowerPoint or Excel
3. Follow the instructions in each file
4. Optional: paste the included AI prompts into ChatGPT or Claude for coaching help

---

## Exercises

1. **Value Proposition.** Define who your customer is, what pain you solve, and why they should care. Output: structured VP document.

2. **Competition Matrix.** Map your competitive landscape and find your positioning opportunity. Output: competitor analysis with scoring grid.

3. **Differentiation Statement.** Articulate what makes you different in a way customers care about. Output: defensible differentiation statement.

4. **Solution 1-Pager.** Create a customer-facing document that leads with outcomes, not features. Output: 1-page solution summary.

5. **Personas.** Define your buyer and user personas with evidence. Output: persona cards with evidence ratings.

6. **Sales Battlecard.** Prepare for competitive conversations with prospects. Output: battlecards for key competitors.
